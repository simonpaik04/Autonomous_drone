# Day 02 - MPU6050 자세 추정과 P 제어

날짜: 2026-07-28

## 공부한 내용

- I2C 통신을 이용한 MPU6050 초기화와 14바이트 센서 데이터 읽기
- 정지 상태에서 1,000회 측정하여 가속도·자이로 오프셋 보정
- 자이로 각속도 적분과 가속도 기반 Roll·Pitch 계산
- 상보 필터를 이용한 자세각 추정
- 목표 각도와 현재 각도의 오차를 이용한 P 제어
- Roll·Pitch·Yaw 보정값을 4개 모터에 분배하는 모터 믹싱
- COM 포트 점유와 시리얼 보드레이트 문제 해결

자세한 내용은 [학습 노트](./notes.md)에 정리했습니다.
